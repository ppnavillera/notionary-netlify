### 🎯 사용 방법

1. **Chrome에서 확장 프로그램 사용**
   - 브라우저 우상단의 Notionary 아이콘 클릭
   - 팝업에서 영어 단어 입력
   - "Search" 버튼을 클릭하여 AI 기반 정의 확인

2. **Notion에 단어 저장**
   - 검색 결과 화면에서 "Save" 버튼 클릭
   - 자동으로 개인 Notion 데이터베이스에 저장
   - 저장된 페이지 링크로 바로 이동 가능

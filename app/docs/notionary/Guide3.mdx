# 2단계: 새로운 페이지에 Integration 권한 부여하기

### 새로운 페이지 만들기

1. Notion에서 새로운 개인 페이지를 생성

2. 새로운 페이지의 이름은 `Integration`으로 만들기




### Integration 권한 부여하기

1. 오른쪽 상단 `・・・` (메뉴) 버튼 클릭
2. 아래에 `연결(connections)` 버튼 클릭 

3. 검색 창에 앞서 정했던 API 통합 이름(예: "나만의 영어 단어장")을 검색하여 선택
4. **"확인(confirm)"** 버튼 클릭

## 데이터베이스 URL 복사하기

1. 오른쪽 상단 `・・・` (메뉴) 버튼 클릭

2. `링크 복사(Copy link)` 버튼을 클릭하여 링크 복사
<Image src="/images/6.png" alt="데이터베이스 URL 복사" />
3. URL 형태 예시:
    
    ```
    https://www.notion.so/myworkspace/Integration-a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6?source=copy_link
    ```
    


> "Integration-xxxxxxxxxx" 이 형태를 꼭 확인해주세요. 형식이 다를 경우 작동이 제대로 이루어지지 않을 수 있습니다.
